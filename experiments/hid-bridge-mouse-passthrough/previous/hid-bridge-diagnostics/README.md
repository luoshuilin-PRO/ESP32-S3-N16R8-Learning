# ESP32-S3 HID-Bridge 独立诊断工具

针对已刷入的官方双板 v0.1.2。自包含目录，Python 3＋pyserial，无需原项目目录；不自动烧录或下载固件。协议变更后仍可能需要适配，不承诺永远无需更新。

## 启动

本机双击 run.cmd。复制整个目录到主机或其他 Windows 电脑也可使用：安装 Python 3（包含 tkinter），执行 `py -3 -m pip install -r requirements.txt`，再运行 `py -3 main.py`。run.cmd 优先本机已有 Codex Python，其他电脑回退 py -3。

配置 config.json 可修改默认 PC 速率列表、统计间隔、查询超时、UDP 地址及 UUID。依赖版本、协议子集固定；协议字段不兼容时拒绝验证，不猜测成功。

## 两种接线模式

**板卡隔离**：只接 COM。能检查端口、匹配波特率下的协议响应和显式复位启动日志；USB 身份未定属于预期，鼠标透传、Makcu M API 和板间通信可能不适用，不当作固件失效。

**双板验收**：M USB 接鼠标、M COM 接副机；P USB 接主机，P COM 可接主机用于本机诊断。17→18、18→17、GND→GND，不互接 5V/3.3V。M 已短接供电焊盘，原生 USB 不接电脑；P 保持未短接。两台电脑各自检测本地 COM，合并查看报告。

## 操作顺序

1. 关闭 NDI 控制软件、Host 和其他串口工具，刷新端口，按设备管理器选端口，不预设 COM3/4。
2. PC 波特率一般 M=115200，P/未定启动阶段=921600。这里选择的是 PC 打开参数，不会改设备。无回应时核对角色及配置，不能直接判定板坏。
3. 点击只读诊断并确认。打开前后 DTR/RTS 低；A5 身份签名、随机 nonce、序号和 CRC 匹配后再读统计。M 完成 A5 统计后关闭并重开同口，再确认身份后一次切到 V4，避免两个程序争用。查询仍会切换软件输入所有者、可能释放其他客户端的软件输入，非“绝对无状态变化”。
4. 观察统计采样期间手动移动真实鼠标。双向 UART 活动只证明观察窗口有链路活动；USB 提交完成也不证明主机程序已消费。
5. Makcu 检查设备类型、API4、设备实际波特率、物理按钮、软件状态快照、插值、屏幕参数及移动状态。不发送 move/click/mask/subscription/reset，纯查询退出不发送软件释放。
6. 保存报告，结果分通过／失败／未验证／不适用，不生成“全部正常”的笼统结论。

## 其他独立动作

- **启动版本（复位）**：仅隔离板卡后明确确认。打开 921600 并 RTS 复位，记录 8 秒原始日志，提取 App version/ESP-IDF；会中断透传并清零统计。ROM 起始乱码属波特率差异，未提取到版本不证明固件不存在。启动日志不是 Flash 签名或完整二进制真实性证明。
- **小幅移动／单击**：双板接好、目标主机打开空白测试窗口后单独确认。V4 相对 +4/-4 或左键单击，不自动循环。停止时不继续回移；异常/退出尝试释放，断线时不保证释放送达。SET 无成功 ACK，主机效果必须另行验证。
- **设备改速**：只适用于 M，固件支持 115200／4M，运行时生效。先测试 PC 驱动是否接受；未通过不发送设置。4M 在此前 CH340 上失败，默认不要改。发送后失败可能设备状态未知，隔离再用显式复位恢复，不自动回滚或复位。P 不支持该 V4 改速。921600 是 P/板间速率，不是 M 可选设备改速。
- **kmboxNet**：Host EXE 必须运行并打开 UDP 服务，填 Host IP/端口/UUID。只发 16 字节 init，核对来源地址及完整 echo ACK；init 会登记会话。只证明该接口握手，不证明 kmNet 全部 API、加密、输入、主机消费或实物 kmbox。默认 127.0.0.1 仅用于 Host 在本机的情况。
- **目标主机事件窗口**：复制工具到真正接 P USB 的主机，在窗口内移动和按下/松开左中右键、上下滚轮。人工确认输入确由桥接鼠标产生才写报告；计数为 0 的项目仍未验证。侧键、游戏、G HUB、1000Hz 长时稳定需另行验收。

## 证据边界和保留

报告保存在 reports/*.json，包含分项证据、统计快照、计数差值、队列和启动日志。可能包含本机端口和用户名相关信息，上传前检查隐私。

HIDBRDG2 不提供 MAC 或精确固件版本；API4 不等于 v0.1.2。串口身份匹配也不是设备密码认证。只检测一块板时不宣称完整双板测试通过。首次 uptime 基线无法证明打开瞬间未复位，只比较两次查询之间连续性。固定配置仅对当前协议支持的功能有效。

## 自动验证

`py -3 -m unittest -v` 使用模拟串口/UDP，不打开实机。实际板卡、改速、复位、主动输入、透传及 UDP 服务仍需按每阶段明确确认；工具开发完成不代表这些实机动作已经完成。
