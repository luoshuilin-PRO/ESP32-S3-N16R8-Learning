# 炼狱 / M4 宏迁移到 HID-Bridge：第一阶段

状态：**源码调查中，未编译、未刷机、未修改 main**。本文件是迁移设计，不是已可运行的固件。

## 来源与目标

- 来源：本仓库 `experiments/macroPassthrough-n16r8/`，旧 SPI 双板方案。
- 目标：`guobaren/ESP32-S3-HID-Bridge` 的双板 UART 透明鼠标代理；不能直接混刷两种固件。
- 现有 HID-Bridge 双板连接：M GPIO17 TX → P GPIO18 RX；M GPIO18 RX ← P GPIO17 TX；共地，不能互连 5V/3V3。

## 已确认行为

| 模式 | 按住实体左键时的输出 | 其他 |
| --- | --- | --- |
| 关闭 / 普通 | 原样透传实体左键 | 右键正常透传 |
| 炼狱 | 左键按下随机 140–155ms，松开随机 20–30ms，循环 | 松开实体左键即停止 |
| M4 | 左键按下 50ms，松开 100ms，循环 | 每次释放向下移动 3 相对单位 |

旧方案中键短按切换宏总开关；开启后长按 800ms 在普通→炼狱→M4→普通间切换。视觉控制优先级高于手动宏，但本阶段**不迁移视觉控制**。

## 目标 API 与局限

目标 Host 的 `LuaScriptRunner.cs` 已提供 `mouse(button,state)`、`move(dx,dy)`、`sleep(ms)`、`IsPressed(arg)`、`OnEvent(event,arg)`。目标 Lua 事件名称为 `pressed` / `released`，鼠标左键为 1，中键为 2，右键为 3。Host 的 `IsPressed` 只读取运行 Host 的 Windows 本机物理输入，**不读取 M 板 USB Host 接入的真实鼠标**。

双板实体鼠标走 M→P 透明 HID 报告通路，Host 软件鼠标指令是独立输入；Lua 发送 `mouse(1,0)` 不保证能解除实体鼠标报告中的左键按下。因此**不能把直接 Lua 改写认定为完整移植**。

## 实施顺序

1. 对照旧固件中鼠标按键状态机、HID multiplexer、视觉优先级和报告生成代码，记录实体左键如何被接管、如何退出。
2. 对照新固件 M/P 报告路径、软件鼠标注入与实体报告合并点；优先在最终输出报告生成前加入受控的左键接管状态机。
3. 设计安全退出：松开实体左键、关闭宏、USB 断连、串口断连或复位时，释放模拟左键；不改变右键、滚轮和普通透传。
4. 编写状态机单元测试：模式切换、随机边界、M4 下移、松开中断、断线释放、实体/模拟左键不冲突。
5. 完成编译与离线测试后，**另行确认**是否在真实开发板上刷写；不覆盖已稳定运行的固件。

## 当前结论

基础接口支持 Lua 原型验证；**精确还原旧固件左键连发需要修改报告协调逻辑**。本阶段不声称实机兼容或完成移植。
