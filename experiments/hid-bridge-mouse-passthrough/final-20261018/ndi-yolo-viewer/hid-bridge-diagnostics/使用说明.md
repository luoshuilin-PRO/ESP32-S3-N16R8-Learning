# 检测工具使用说明

## 第一次使用：先做只读诊断

1. 关闭 NDI YOLO 软件、hid-bridge-python、Host 以及其他串口工具，避免占用端口。
2. 在项目根目录运行 `install.cmd` 后，双击 `start-diagnostics.cmd`。工具启动不会自动连接板子。
3. 点击“刷新端口”，在日志中查看端口描述，再选择实际接入的 COM。
4. 选择 PC 波特率：A/M 板已接鼠标、角色确定时一般 115200；B/P 板或隔离未定角色一般 921600。不要先选 4000000。
5. 点击“只读诊断”，阅读提示并确认。
6. 等待本轮完成，查看每一项的结论和证据，再点击“保存报告”。

只读诊断不注入鼠标、不复位，但查询会切换软件输入所有者，因此先关闭其他控制程序。

## 已接好的 A/M 板检测

A 板 COM 接运行本工具的电脑，原生 USB 接鼠标，双板已接好时：
- 刷新后按端口描述和设备管理器选择实际 COM，不预设 COM3。
- PC 波特率选择 115200。
- 执行“只读诊断”。
- 统计采样期间可手动移动真实鼠标，不需要点击。

预期：HIDBRDG2 角色 M/MOUSE_HOST、合法协议回应、Makcu API4、设备波特率 115200。板间 UART 有活动不等于目标主机已消费鼠标。

## 只接 COM 的隔离板卡

断电后拆掉鼠标、原生 USB 数据线及板间线，只保留 COM：
- 一般选 921600，先尝试只读诊断。
- UNRESOLVED（身份未定）是隔离情况下的预期，不是固件损坏。
- Makcu、双板通信、鼠标透传可显示“不适用”或“未验证”。

要确认精确 App version，点击“启动版本（复位）”，再次确认已隔离。这个动作会复位板子、中断链路、清零 RAM 统计，采集约 8 秒。版本出现在报告里；开始的乱码或没有读到版本不单独证明固件失效。

## 双板透传验收

保持原接线：A17→B18、A18→B17、GND→GND；不互接 5V/3.3V。A COM 供电及调试、A USB 接鼠标；B USB 接主机，B COM 可接电脑。

1. 将整个工具目录复制到目标主机；该电脑必须实际接 B 板原生 USB。
2. 打开工具，点击“主机事件窗口”。这一步不用打开串口。
3. 鼠标停在事件窗口中，测试移动、左右中键的按下/松开、滚轮上下。
4. 观察各项计数增加，确认是桥接鼠标产生，而不是另一只鼠标。
5. 点击“记录人工验收”，再保存报告。

没观察到事件的项目保持“未验证”。侧键需另用浏览器鼠标测试验证，本窗口不覆盖侧键、游戏消费或 G HUB。

## 软件输入测试：另外确认

先在目标主机打开空白事件窗口，松开物理按钮。副机选择 A 板 COM3、115200：
- “小幅移动测试”：相对右移 4 单位，再左移 4 单位；加速度可能导致不精确回到原点。
- “单击测试”：软件左键按下约 50ms，然后释放，仅一次，不循环。

两者都弹出独立确认。停止会撤销后续动作，已发送的移动不会被撤回。写入成功不等于主机收到；请看主机事件窗口。串口断线时释放可能未送达，检查主机有无持续按下状态。

## kmboxNet 握手

这个接口由 HID-Bridge Host 软件提供，不是 ESP32 COM 自带 UDP。
1. 打开 Host 软件并启用 UDP 服务；测试只读串口与运行 Host 不要争用同一 COM。
2. 填 Host 实际 IP、服务端口和 8 位十六进制 UUID。127.0.0.1 只表示当前电脑。
3. 点击“kmboxNet 握手”并确认。
4. 工具只发送 init，校验返回地址与完整 ACK，不发送鼠标输入。

没有运行 Host 或地址错误时，失败不表示 ESP32 固件损坏。握手通过不证明完整 kmNet API、实物 kmbox 或鼠标输出。

## 波特率：区分两个地方

- “PC 波特率”：只决定本工具用什么速率打开串口，不改变设备。
- “M 设备改速”：真的发送设备设置，第一轮不要使用。P 不适用。4M 在此前 CH340 上失败；改速失败可能状态未知，需要隔离后显式复位恢复。
- 板间 UART1 的 921600 与 M COM 的 115200 是两条不同通路。

## 结果怎么理解

- 通过：当前这一项有匹配证据，不代表其他项目通过。
- 失败：本项检测出现错误，结合细节区分占用、波特率、网络、协议或硬件。
- 未验证：证据不足或需要主机配合，不是判定故障。
- 不适用：当前角色/隔离接法不具备测试条件。

“保存报告”会生成 reports/日期时间.json。启动日志和端口信息可能包含本机信息，上传前检查隐私。

工具默认不会烧录、不会自动更改设备速率、不会自动复位或自动点击。首次建议只测端口＋固件协议，保存结果后再决定下一项。
