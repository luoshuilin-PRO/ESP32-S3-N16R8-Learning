## 当前接线

官方 HID-Bridge v0.1.2，两板使用同一固件。A/M 原生 USB OTG 接真实鼠标，A COM 接控制电脑；B/P 原生 USB 接目标电脑。单机时两者是同一台电脑。

| 信号 | 接法 |
| --- | --- |
| UART TX/RX | A GPIO17 → B GPIO18 |
| UART RX/TX | A GPIO18 ← B GPIO17 |
| 共地 | A GND ↔ B GND |

不要互接 5V/3.3V，也不要沿用 macroPassthrough 的旧 SPI 八根信号线。现有板子仅 A 短接 OTG 供电焊盘，B 未短接；新板型须核对原理图。烧录前隔离单板，仅保留当前板烧录 COM。
