## 接线

断电连接 A/B 两板：GPIO 39、40、41、42 和 10、11、12、13 各自同号直连，再用一根 GND 共地。MOSI/MISO 不交叉；两板之间不互接 5V 或 3.3V。

```text
鼠标 → A 原生 USB（A 的 USB-OTG 供电焊盘已短接）
独立 5V USB 电源 → A COM
A ↔ 8 根 SPI + 1 根 GND ↔ B
B 原生 USB → 电脑，负责 USB HID
B COM → 电脑，负责供电、日志及 VC1 指令
```

B 未短接 USB-OTG 供电焊盘。A 的 USB Host 不应在其 COM 供电时再接电脑等有源 USB 端。普通外置 LED 要单独串联限流电阻；当前固件使用 B 板 GPIO48 板载 RGB，无需再接外置 LED。若再次隔离烧录 B：先全部断电，移除 B 的板间线和原生 USB，只保留 B COM；核对板卡身份后烧录，完成后断电恢复接线。

历史排错：A 鼠标有灯却不能移动时，用户用万用表发现 SPI 线接错，修正后恢复；此前 B 板 5V 跨板给 A 供电导致电压下降，现采用 A 独立供电。最初误以为原始演示固件支持前进/后退侧键，用户恢复原版回测后确认当时混淆了两只鼠标；当前链路未证实侧键可用，不能推广为所有鼠标都不支持。Rapoo 与老版 G502 的滚轮结果也不同。

## 当前行为

| 操作 | 行为 |
|---|---|
| 上电 | 手动宏关闭 |
| 中键短按 | 开/关手动宏；开启进入普通模式 |
| 开启后中键长按 800ms | 普通 → 炼狱 → M4 → 普通 |
| 普通或关闭 | 左键正常透传；右键始终正常透传 |
| 炼狱按住真实左键 | 左键按下 140–155ms、松开 20–30ms，循环至松键 |
| M4 按住真实左键 | 左键按下 50ms、松开 100ms，每次释放向下移动 3 个相对单位 |
| 视觉启用且红名存在 | 视觉独占左键：按下 50ms、松开 100ms；暂停手动左键宏，不附带压枪 |
| 红名消失、F8 停止或通信超时 | 取消视觉点击，恢复真实左键及当前手动模式 |

视觉开关由电脑工具独立控制，不受中键手动宏开关控制。接管已经按下的 USB 左键时先释放 5ms；首次及重新识别没有旧版额外约 100ms 等待。真实左键如果仍被用户按住，视觉结束后会恢复按下或对应手动宏。右键 USP、鬼跳和原始 A-Z 演示宏均不在当前活动状态机里。关闭/普通模式板载 RGB 熄灭；炼狱亮灭各 500ms；M4 各 2000ms。

## Windows 识别工具

[vision-controller](vision-controller/README.md) 从固定屏幕区域采图，按 HSV、像素数量和分布范围判断红色；它不做 OCR，也不识别游戏进程或窗口焦点。PC 向 B 的 COM 串口发送 16 字节 VC1 状态消息，由 B 自主生成点击。B 的原生 USB 仍负责 HID 输出。命中许可有效期 180ms，过期或停止会撤销；不是单字节 `0x01` 协议。

归档的 `config.json` 是当前工作参数：1920×1080 屏幕中的 ROI `(911,595,84,25)`、10ms 目标间隔、1 帧确认、至少 10 个红色像素。它们是用户当前调试值，不代表实际达到 100Hz 或适用于其他分辨率。界面会显示实际循环 Hz、采集识别耗时与串口往返耗时；这些数值还未从用户本轮实测中归档。素材回归只覆盖已有画面和名字，不等于真实场景误触率已确定。

## 摄像头扩展与延迟

[CAM 可行性记录](CAM可行性.md) 已按用户现有 ESP32-S3 N16R8 CAM + OV2640 更新。摄像头可以避开 Windows 截图与串口往返，但新增屏幕显示、曝光、取帧、处理和 C→B 通信；延迟是否降低，须用实际首击/停止延迟对比，不能按板卡型号推断。当前视觉点击完整周期仍是 150ms；换摄像头本身不会改变 B 板的点击节奏。没有对 CAM 编译、接线或烧录。

## 源码与验证边界

- [firmware/usb-input](firmware/usb-input) 是早期 A 适配版；[firmware/usb-output](firmware/usb-output) 是已烧录的当前 B 版。保留上游文件和许可证；上游 README 描述原始演示，不代表此分支实际行为。
- 本机用 ESP-IDF `v5.4-dirty` 构建，不是 v5.5.4。A/B 均为 ESP32-S3，Flash 16MB、Octal PSRAM 8MB；第二组 GPIO 固定为 10/11/12/13。
- 没有公开二进制、构建目录、完整日志、设备 MAC 或本机路径。历史 RIGHT-USP 版可查提交 `115400b`，初次适配快照可查 `953b5bc`。
- 当前待测：真实游戏首击/停止延迟，实际循环 Hz 与耗时；A/B 透传和视觉优先切换；SPI 长期稳定性；侧键 HID 描述符兼容性。
