# Windows 红名像素检测 / B 板 VC1 固件

## 启动

双击 start.cmd。本机使用已安装的 Codex Python；其他电脑安装 Python（含 tkinter）和 requirements.txt。
默认仅预览，不打开串口。当前区域是 1920x1080 图片上的 x=911,y=595,width=84,height=25。
选择显示器后核对 ROI；其他分辨率需要重新框选，不能直接套用该坐标。
可导入素材采集工具的 JSON。导入 BMP 所保存的坐标属于图片，不保证其桌面位置。

1. 不勾选连接 B 板，开始预览，检查局部图和黑白掩膜是否正确。
2. 停止预览，确认 B 板 COM 和原生 USB 均连接电脑，关闭串口监视器。
3. 勾选连接 B 板，选择 COM4，开始预览。原生 USB 状态应显示就绪。
4. 点击启用输出并确认，窗口最小化；三秒内切回目标画面。
5. F8 停止输出。恢复软件窗口也会停用输出。停止按钮结束预览并关闭串口。

固定显示器区域模式不识别游戏名称、窗口失焦或遮挡。切换其他应用前先按 F8 停止。
不做 OCR，不检查名字内容；相同颜色的其他物体或文字仍可能误判。
参数在重新开始预览后生效，保存参数不会保存启用输出状态。

## 识别和时序

使用 Pillow 截图、NumPy 计算 HSV，避免新增大型 OpenCV 依赖。
HSV 使用 OpenCV 标度 H=3..12、S>=150、V>=140；红色占比<=65%，分布范围至少5x3。代码内缺省最少20像素、连续两帧命中、20ms采样；本仓库保存的 `config.json` 调试值为最少10像素、1帧确认、10ms采样。保存值会覆盖代码内缺省值。
确认帧数可选1～3帧，一帧未命中始终立即发送停止。界面采样间隔可设10～100ms（目标100～10Hz）。
设定100Hz不代表实际达到100Hz；实际频率根据连续采集循环起点统计，包含截图、处理、串口等待和休眠。
另显示采集＋识别耗时及串口往返耗时，不代表游戏开火延迟。预览画面最多刷新10次/秒，不限制识别循环。
参数在停止并重新开始预览后生效；一帧确认和较低像素阈值可能更快，也更容易误触发。
采集处理超过100ms则报错停止，原有超时保护保持不变。
本机样本回归23张通过不代表真实游戏准确率：17张同名字红名，6张无红名，缺乏独立测试集。公开仓库不附游戏截图，因此独立检出时图片回归测试显示跳过；将原 `material-capture/samples` 放在本工具同级目录后才会执行该项。
误分类文件仅在测试中校正，原始素材没有移动。

B 板收到新鲜有效命中消息后自主生成左键按下50ms、松开100ms的连续点击，无压枪位移。
2026-10-08 B板已更新为VISION-FIRST固件，与现有PC软件/VC1协议兼容，不需要替换软件。
已取消首次/重新识别的额外约100ms等待；若接管时USB左键已经按下，先松开5ms再开始自动点击。用户反馈实际触发仍感觉慢，尚无本轮实际循环 Hz、采集识别与串口往返数据；以下参数不代表已测端到端延迟。
连续点击仍为50/100ms，界面采样间隔不是点击间隔。确认帧数、采样间隔可自行调整，建议先20ms+1帧。
PC 不是逐个排队发送点击，而是每张新采集图片更新短时有效的检测状态。
STOP 立即取消自动按下和后续点击；断线/卡死180ms未更新则自动停止并要求重新握手。
停止仍受采集、USB调度和通信延迟影响，不是零延迟。USB不可用期间不会保留待补发点击。

视觉优先：新鲜红名状态存在时，视觉独占左键，暂停炼狱/M4手动左键宏，无自动压枪；物理按钮状态继续记录。
红名消失、F8停止、串口超时后，恢复真实左键及选定宏模式；仍按住真实左键时会恢复按下/对应宏，而非强制停止手动操作。
移动、右键、滚轮透传保持原样。没有红名时普通模式的手动长按/拖动正常，视觉接管期间不能维持左键拖动。
中键宏总开关只控制原有手动宏；视觉输出由PC显式启用/停止，互相独立。
右键所有模式正常透传。USP和鬼跳已从活动状态机移除。M4下压仍为3。

## 协议

115200 8N1，16字节：ASCII VC1!（4）+小端序列号uint32（4）+命令（1）+零保留（3）+CRC32（4）。
CRC32覆盖前12字节，与zlib.crc32一致。命令0=STOP，1=当前新帧命中，2=HELLO。
B 响应 `VC1 ACK <seq> <command> <usb_ready>`。HELLO不触发点击；超时必须重新开始连接。
开启串口前关闭DTR/RTS，仍不能保证所有USB串口驱动都不会瞬时复位。
只兼容本次VC1固件，不兼容此前单字节0x01设想或旧原始固件。

## 接线

A原有鼠标/独立供电保持不变；A/B原有8根SPI+GND保持不变，不互接电源。
B COM接电脑供电/指令；B原生USB接电脑作HID。B不短接OTG供电焊盘。
烧录时按用户已确认的隔离方式，仅接B的COM。不要带电插拔杜邦线。

## 测试

`python -m unittest -v test_controller.py`：协议、确认逻辑、ACK超时测试，无硬件动作；有本地素材时才执行图片回归。
固件启动会运行macro/vision状态机自检；串口诊断需独占COM。
源代码在相邻v1-firmware，构建脚本是工作区build-v1.ps1。
